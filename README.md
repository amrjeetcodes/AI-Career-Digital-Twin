# 🚀 AI Career Digital Twin 2.0

An AI-powered Career Analysis Platform that helps students analyze resumes, calculate ATS scores, predict career paths, identify skill gaps, generate interview questions, and visualize skills through an interactive dashboard.

# 📌 Project Overview

AI Career Digital Twin 2.0 creates a digital profile of a student's career by analyzing resumes, certificates, skills, and professional profiles.

The platform provides:

- Resume Analysis
- ATS Score
- AI Career Prediction
- Skill Gap Analysis
- AI Interview Questions
- AI Career Report
- GitHub Analysis
- LinkedIn Profile Analysis
- Recruiter Dashboard
- Resume Comparison
- Skill Visualization
- Certificate Verification

# ⚙ Installation

Clone Repository

```bash
git clone https://github.com/amrjeetcodes/AI-Career-Digital-Twin.git
```

Move to project

```bash
cd AI-Career-Digital-Twin
```

Install dependencies

```bash
pip install -r backend/requirements.txt
```

Run Backend

```bash
cd backend
uvicorn main:app --reload
```

Open Frontend

```
frontend/dashboard.html
```
